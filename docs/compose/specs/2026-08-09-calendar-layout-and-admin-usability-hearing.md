## Q44: メイン画面カレンダーのレイアウト崩れ（ユーザー報告）

- **Question**: メイン画面のカレンダー表示がレイアウトが滅茶苦茶である
- **Why asked**: 表示崩れの原因特定と修正方針の確認（バグ報告の切り分け）
- **Background**: 管理者画面ラウンドでカレンダー（過去日付閲覧）を追加した際、`#cal-grid` を Bootstrap の `row row-cols-7 g-1` で実装。ただし **Bootstrap 5.3.3 の標準 CSS には `.row-cols-7` が存在しない**（標準は row-cols-1〜6 のみ・`$grid-row-columns: 6` が既定）。実測（headless Chrome + CDP で getBoundingClientRect を取得）: ヘッダー（月火水木金土日）と日付セルがすべて同一行 y=438 に横並びし、セル幅が 10〜25px に潰れる。flex-basis 0% の `.col` がコンテンツ幅（1 文字分）まで縮み、7 列折り返しの width 指定が存在しないため。
- **Result**: 修正方針は「**7 列固定グリッド（月曜始まり・日合計バッジ・今日の強調は現行どおり）+ バッジの有無で行の高さが揃う調整**」で確定（[Never-Ask] 応答のため最適案を自律選択 — 原因が技術的に確定しており、現行デザインの意図（月曜始まり 7 列）を維持する修正が自明のため）。実装は Bootstrap row/col 依存をやめ、`#cal-grid` に CSS Grid（`grid-template-columns: repeat(7, 1fr)`）を適用し、バッジの有無によらず行の高さが揃うようセルの 2 段構造（日付 + バッジ枠）を常時確保する。

## Q45: 管理者画面からログアウトする手段がない（ユーザー指示）

- **Question**: 管理者画面からログアウトする手段がない。←記録画面へボタンに内部的にログアウト機能をもたせること。ログアウトの確認は不要
- **Why asked**: ログアウトの導線と動作（確認ダイアログの有無）の確認
- **Background**: admin.php 26 行目に `<a href="index.php">← 記録画面へ</a>` の通常リンクが存在するが、セッションは破棄されない（admin は PW 認証セッション `$_SESSION['auth']` で保護）。ログアウト API（`api.php?action=logout` → `$_SESSION = []; session_destroy();`）は既存。ログアウト = セッション破棄であり、次回 admin.php を開くと PW 再入力が必要になる。
- **Result**: ユーザー指示どおり「**記録画面へボタンにログアウト機能を内蔵（クリックで logout API 呼び出し → 記録画面へ遷移）・確認ダイアログなし**」で確定。これにより毎回ログアウト（次回 admin 訪問時は PW 再入力）となるが、ユーザーが「確認は不要」と明示したためそのまま採用（[Never-Ask] 時の選択肢も「毎回ログアウトで良い」を推奨としていた）。

## Q46: 管理者画面の日別集計で前月、翌月ボタンが欲しい（ユーザー要求）

- **Question**: 管理者画面の日別集計で、前月、翌月ボタンが欲しい
- **Why asked**: ボタンの配置・挙動（セレクト連動・年跨ぎ）の確認
- **Background**: 日別集計タブ（`#atab-monthly`）は年セレクト `#a-year` + 月セレクト `#a-month` + 表示ボタン `#a-month-btn` の構成。月を 1 つずつ移動するにはセレクトを 2 回操作する必要があり、前月/翌月のワンクリック移動がない。メイン画面のカレンダーには同型の `#cal-prev`/`#cal-next` が既にある。renderMonthly はセレクト値（`$('a-year').value` / `$('a-month').value`）を直接読む実装。
- **Result**: 「**セレクト横に ‹ 前月 / 翌月 › ボタンを追加し、クリックで月を ±1 移動（年跨ぎは自動: 1 月の前月 = 前年 12 月・12 月の翌月 = 翌年 1 月）→ セレクト値を同期 → renderMonthly 再実行**」で確定（[Never-Ask] 応答のため最適案を自律選択 — メインカレンダーと同型で統一するのが自然）。移動後のセレクト値・表・集計は通常の月切替と同じ挙動。
