## 2. デモデータ仕様（seed_demo.php）

- 期間: **2026-06-01〜2026-08-07（68日）**・時刻 **09:00〜17:05**（HH:MM は同一日・同一分の重複なし・秒はランダム）
- 各記録の count: **1**
- 日ごとの件数: **5〜10件・中央値 5・合計 401件**（決定的に構成: 35日=5件 / 5日=6件 / 28日=7件 → 175+30+196=401・中央値5。日割り当ては固定シード mt_srand(20260807) でシャッフル）
- 既存データ: **範囲内（2026-06-01 00:00〜2026-08-08 00:00）のレコードは差し替え**（削除→挿入・トランザクション）。範囲外は温存
- 冪等: 再実行しても合計 401 件
- 使用: `PARK_DB_PATH=<path> php scripts/seed_demo.php`（省略時は既定 data/parking.db・DB_PATH 解決は lib/config.php と同じ優先順）
