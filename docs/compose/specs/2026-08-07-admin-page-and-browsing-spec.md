## 要件

### R1. 管理者画面（admin.php）新設
- URL: **https://debugprint.com/parking/admin.php**（parking 直下・単一ファイル・Q34）
- **開くと PW ダイアログ（1234・現行 login API）が表示**され、認証セッション中のみ閲覧・操作可（Q37）。
- 未認証時のデータ API アクセスは 401（delete / update / stats / auth は要認証）。
- メイン画面（index.php）に「管理者」リンクを追加（footer 等）。

### R2. メイン画面（index.php）の再編
- **撤去**: 日別集計タブ・日詳細モーダル（過去分）は管理者画面へ完全移動（Q35）。
- **維持**: 記録（枚数 1〜999）・今日の合計・今日の一覧（時間昇順）・60 秒自動更新チェック。
- **削除**: 本日分のみ残す（今日の一覧の各行削除ボタン・PW 入力・任意選択・Q35/Q36）。
- **過去日付閲覧（新機能・Q41/Q42）**: 画面上部の本日日付クリック → カレンダー表示（年・月選択 + 日付グリッド + 各日に合計枚数バッジ）→ 日付クリックでその日の詳細モーダル（時刻・枚数・**見るだけ・削除ボタンなし**）。**PW なしで公開**。過去日付への記録追加は不可。
- 自動更新チェックは表示中のパネル（今日一覧・カレンダー・日詳細）に適用。

### R3. API 変更（api.php）
- **`monthly` / `day` を公開化**（認証不要）— メインのカレンダー閲覧のため（Q42 で集計データの公開を承認）。レスポンス形式は現行のまま。
- **`auth`（新設・要認証）**: GET → 200 `{ok:true}` / 401。admin.php のロード時の認証確認用。
- **`update`（新設・要認証）**: POST JSON `{id, count?, created_at?}` — レコードの訂正（枚数・日時変更・Q40）。
  - 枚数は 1〜999（不正 400 `{"error":"invalid count"}`）
  - 日時は `YYYY-MM-DD HH:MM`（秒は 00 に正規化・JST・不正 400 `{"error":"invalid datetime"}`）
  - id が存在しない → 404 `{"error":"not found"}`
  - 成功 → 200 `{ok:true}`（更新後の created_at を返す）
- **`stats`（新設・要認証）**: GET `year` と `month`（月単位・`month` 省略時は年単位）→ 分析データ。
  - 200 `{year, month?, dow:[{dow,count,sum}], hour:[{hour,count,sum}], summary:{days,total,records,max_day:{date,total}|null,avg_per_day}}`
  - `dow`: 0=日曜〜6=土曜・件数と枚数合計
  - `hour`: 0〜23・件数と枚数合計
  - `summary`: 対象期間の日数・総枚数・総件数・日別最大（日付と枚数・全期間 0 なら null）・日別平均（total/days・小数1桁）
  - 年・月の形式不正は 400 `{"error":"invalid period"}`
- `add` / `delete` / `login` / `logout` は現行のまま（delete は要認証・add/login は公開）。
- レスポンスは JSON・成功時のステータスコードは現行仕様に従う。

### R4. 管理者画面の機能
1. **日別集計**: 年・月指定の日別合計表（日・件数・枚数）+ 月合計（既存 monthly の表示を移動）。
2. **日詳細 + 全編集**: 日付クリック → その日のレコード一覧（時刻・枚数）。**各行に「編集」「削除」ボタン**。
   - 編集: モーダルで枚数（1〜999）と日時（datetime-local・分まで）を変更 → `update`。
   - 削除: 確認後 `delete`（現行 API・要認証）。
   - 過去分を含む全期間が対象（Q35/Q36）。
3. **月報（Q38）**: 指定月の日別合計表 + 月合計 + **日別合計の棒グラフ**（Chart.js・jsDelivr CDN）。
4. **年報（Q38）**: 指定年の月別合計表 + 年合計 + **月別合計の棒グラフ**。
5. **分析（Q39）**: 対象期間（年・月セレクタに連動）で
   - **曜日別集計**: 月〜日の件数・枚数・平均 + 棒グラフ
   - **時間帯別分布**: 0〜23 時の件数・枚数 + 棒グラフ
   - **期間サマリ**: 総件数・総枚数・日別最大（日付付き）・日別平均
   - 期間が 0 件のときは「記録がありません」表示（グラフ非表示）。
6. 期間セレクタ: 年（プルダウン）・月（プルダウン or 前月/翌月）。変更で集計・月報・分析が連動更新。

### R5. UI 部品（両画面）
- PW ダイアログ: 既存の Bootstrap モーダルパターン（backdrop static・keyboard false・1234 初期値・DEMO 注記）を admin.php にも適用。
- カレンダー（メイン）: 月曜開始の 7 列グリッド（モバイルは 7 列のまま・セルはコンパクト）。各日セルに日付と合計枚数バッジ（0 は空表示・今日は強調）。前月/翌月ナビ + 年・月表示。Bootstrap grid で実装（外部カレンダーライブラリ不使用）。
- Chart.js は jsDelivr CDN（Bootstrap と同じ配信元・到達性確認済み）。

### R6. 認証・セキュリティ
- PW 検証は現行のまま（login: hash_equals + session_regenerate_id(true) + sleep(1) スロットル）。
- admin.php はロード時に `auth` で認証確認 → 未認証なら PW ダイアログ表示（コンテンツは表示しない）。データ API（update/delete/stats）は要認証のため、JS 無効や直接 API 叩きでもデータ漏えいなし。
- メインの公開 API は閲覧・記録のみ（add/monthly/day）。データ本体（レコード詳細）の公開は day の範囲（Q42 承認）。
- セキュリティヘッダ（F4）は両画面に適用。
